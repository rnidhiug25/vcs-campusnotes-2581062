
# CampusNotes

CampusNotes is a simple web-based academic notes manager.

## Features
- Add academic notes.
- Enter a note title and description.
- View notes on the webpage.
- Simple and user-friendly interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open the CampusNotes folder.
3. Open index.html in a web browser.
